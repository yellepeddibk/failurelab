# Security Training Handbook

Every employee completes security training within the first thirty days and repeats
it annually. Engineers additionally complete secure coding training covering
injection, authentication, and secret handling.

Phishing simulations run quarterly. Reporting a simulated phish is the expected
outcome, and clicking one triggers a short follow-up module rather than any
disciplinary action.

Suspected real incidents are reported to the security channel immediately. Reporting
a false alarm is always acceptable.
