# Glossary

Escalation owner: the engineer responsible for first response to alerts for a given
service during a given shift.

Break-glass: temporary elevated production access granted during an incident,
requiring a second approver and limited in duration.

Canary: a deploy stage that routes a small fraction of traffic to a new version
before full rollout.

Drain: the act of removing traffic from a region or instance so that in-flight work
completes before the target stops receiving new requests.

Backlog: the count of messages accepted for delivery but not yet delivered.
